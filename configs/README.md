# Config Templates

Copy these into the matching runtime locations and fill in your local values.

- `env.example` -> `WatchDog/.env`
- `wrapper.yaml.example` -> `WatchDog/config/wrapper.yaml`
- `auto_update-patches.yaml.example` -> `WatchDog/plugins/auto_update/patches.yaml`
- `watchdog_helper-common.toml.example` -> `WatchDog/atm11/config/watchdog_helper-common.toml`
