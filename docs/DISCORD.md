# BlackGrid — Discord integration and AI guild administration

**Status:** approved design direction; BlackGrid Core enforces action permissions even if the bot has Discord Administrator.

### 4.3 Discord first-class controller
One guild can span the network. BlackGrid tracks Discord IDs for guild, roles, channels, and game-instance mapping. Provision a new instance => prepare its scoped channels, status, chat bridge, scoped votes, and access policy; failures lead to repairable partial state and idempotent retries, not duplicates. Guild-wide votes coexist with per-instance votes. Discord API permissions and rate limits are handled, without requiring OpenCode for normal operations. Prevent feedback loops, impersonation and unwanted disclosure in chat bridging.

### 4.3d Full-guild Discord administration by BlackGrid AI (approved product direction; planning only)

**Intent:** The first-party BlackGrid Discord bot is an integrated, full-guild administrative interface for the AI co-administrator—not merely a voting, ticketing, or chat-relay bot. The owner intends to grant the bot Discord's **Administrator** permission, place its role as high as Discord hierarchy permits, and configure relevant gateway intents and API permissions. Its full capability is available through **typed, auditable BlackGrid Core tools**; OpenCode never receives the bot token, a raw unrestricted Discord REST proxy, or direct permission to bypass the action gateway. Guild ownership, role-hierarchy restrictions, privileged intents, API rate limits, and Discord's own capabilities remain hard external constraints.

**Read and monitor:** Within the bot's actual accessible permissions/intents, inspect guild channels/categories/threads/forum posts, message content/history, reactions, member and role information, permission overwrites, moderation records and operational events. Message-content access requires the relevant Discord privileged intent when applicable; do not promise access to deleted or unavailable history. Handle private-channel data as scoped sensitive information, never automatically relay it publicly or into unrelated AI contexts.

**Write and organize:** Independently send/edit messages and announcements; create/manage discussion threads and forum posts; provision, rename, move, archive and configure channels/categories; manage appropriate guild settings, role assignments and channel overwrites; arrange Discord topology for new Minecraft instances; provide community help, events and governance announcements. Keep channel mappings idempotent and recover from partial failures.

**Delete and moderate:** Delete messages within supported Discord API limits, remove spam, lock threads, timeout/kick/ban/unban members when authorized, review incidents, and enforce server rules. Routine low-risk moderation can run autonomously according to predefined policy; log the principal, scope, evidence, action and result, and give an appeal/escalation path for disputed or high-impact moderation. Never claim unperformed or technically unsupported Discord actions occurred.

**Autonomous initiative:** The AI can identify spam, broken channel organization, repeated questions, needed community resources, and moderation/operational anomalies, then start approved investigations or perform allowlisted routine operations without waiting for direct prompts. AI-suggested changes to guild policy, administrator permissions, large-scale deletion, bulk bans, or guild-wide restructures require elevated human authorization through BlackGrid Core. Protect the top community authority ('Deadhead'), owner emergency access, and designated protected roles/channels against autonomous changes.

**Security separation:** The bot's broad Discord Administrator permission is **transport-level capability, not a blanket authorization for AI behavior**. Core enforces global/scoped grants, policy gates, risk categories, confirmations for destructive operations, audit trails, rate and volume limits, and anti-prompt-injection treatment for all Discord content. Human operators can revoke AI access or shut down the AI without losing deterministic bot governance, ticketing, or server-bridging functions. Discord guild Administrators retain the explicitly specified ballot cancellation authority. The AI cannot modify or grant its own permissions.

**Acceptance:** With appropriate bot privileges, BlackGrid AI can read an authorized channel, post a message, edit/remove its own or moderatable messages, create/configure a channel, handle an authorized spam incident, and record each action. An attempt to delete a whole category or modify protected admin roles is blocked pending elevated authorization. Disabled OpenCode does not interrupt core Discord operations. Tests cover permission errors, privileged-intent gaps, missing messages, role-hierarchy failures, retries, audit evidence and token non-disclosure.
