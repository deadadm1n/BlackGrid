# WatchDog Helper

WatchDog Helper is the Minecraft-side NeoForge helper mod for a Minecraft server.

It gives WatchDog server-side visibility and control hooks, and it carries gameplay features such as economy commands, shop/exchange commands, MOTD/rules messages, bridge broadcasts, and placement protections.

Build locally with:

```powershell
.\gradlew.bat clean build
```

The release asset is built by GitHub Actions from `watchdog-helper-v*` tags.
